# Data Manifest

All paths are project-relative. Large data files are not included in this review package.

| Path | Purpose | Required | Generated by |
| --- | --- | --- | --- |
| `data/gene_distributions.train_donor.stage1.store` | Train cell-side gene distribution store | Yes | cell embedding and distribution preprocessing |
| `data/gene_distributions.eval_donor.stage1.store` | Eval cell-side gene distribution store | Yes | cell embedding and distribution preprocessing |
| `data/benchmarks/v2_textsplit_strict/text/train_text50_strict.store` | Masked strict train text evidence store | Yes | `split_text_evidence_store.py` |
| `data/benchmarks/v2_textsplit_strict/text/eval_text50_strict.store` | Masked strict eval text evidence store | Yes | `split_text_evidence_store.py` |
| `data/noise_text/easy_random_text_train_v2_1000.pubmedbert.npz` | Encoded easy-noise bank for train text | Yes for noise experiments | `encode_easy_noise_bank.py` |
| `data/noise_text/easy_random_text_eval_v2_1000.pubmedbert.npz` | Encoded easy-noise bank for eval text | Yes for noise experiments | `encode_easy_noise_bank.py` |
| `data/stage1_instance_scores.train_donor.allgenes.real.npz` | Train Stage1 instance scores | Yes for Full scGATES | Stage1 preprocessing |
| `data/stage1_instance_scores.eval_donor.allgenes.real.npz` | Eval Stage1 instance scores | Yes for Full scGATES | Stage1 preprocessing |
| `results/textsplit_consistency/gene_sets/strict_text_min8_genes.txt` | Gene allowlist for strict text_min8 | Yes | `make_text_evidence_gene_sets.py` |
| `data/gene_id_maps/all_train_eval_genes_EntrezID.csv` | Gene to EntrezID mapping | Optional | external mapping |
| `data/gene_id_maps/random_gene_alias_seed42.csv` | Gene to random alias mapping | Optional | `build_gene_identifier_replacement_tsv.py` |
| `data/benchmarks/v2_textsplit_strict_unmasked_exact/text/*.store` | Exact unmasked strict split stores | Optional | `build_exact_unmasked_textsplit_store.py` |
| `data/benchmarks/v2_textsplit_strict_entrezid_exact/text/*.store` | Exact EntrezID strict split stores | Optional | `build_exact_unmasked_textsplit_store.py` |
| `data/benchmarks/v2_textsplit_strict_randomgene_exact/text/*.store` | Exact random-alias strict split stores | Optional | `build_exact_unmasked_textsplit_store.py` |

## Mini Example Data

A small real-data subset is already included in `example_data/`. It contains cell-side distribution stores, text evidence stores, Stage1 instance-score inputs, and text previews for checking input formats and the training interface.

The subset provenance is recorded in `example_data/README.json` and each store's `metadata.json`. The `synthetic` field is `false`.

See [the example data guide](example_data/README.md) and the small input command in [README.md](README.md). Full-data preparation is described in [the data preparation notes](docs/DATA_PREPARATION.md).

## Stage1 Upstream Module

The upstream module for generating Stage1 neighbor or instance-score files is
included at:

```text
stage1_neighbor_prior/
```

The current main training script does not regenerate Stage1 scores by default.
It reads precomputed `.npz` files through:

```text
--instance-score-npz
--eval-instance-score-npz
```
