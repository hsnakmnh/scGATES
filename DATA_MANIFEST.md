# Data Manifest

All paths below are relative to the repository root. The small input example is included under `example_data/`; full-experiment inputs must be prepared separately.

## Main Alignment Inputs

| Path used by the Bash recipes | Purpose | Preparation |
|---|---|---|
| `data/gene_distributions.train_donor.stage1.store` | Training cell distributions | External cell embedding extraction and store construction |
| `data/gene_distributions.eval_donor.stage1.store` | Evaluation cell distributions | Construct from held-out donors |
| `data/benchmarks/v2_textsplit_strict/text/train_text50_strict.store` | Training text evidence | Text encoding and `split_text_evidence_store.py` |
| `data/benchmarks/v2_textsplit_strict/text/eval_text50_strict.store` | Held-out text evidence | Same encoder and a disjoint evidence split |
| `data/stage1_instance_scores.train_donor.allgenes.real.npz` | Per-instance training scores | External score preparation, aligned to the training store |
| `data/stage1_instance_scores.eval_donor.allgenes.real.npz` | Per-instance evaluation scores | External score preparation, aligned to the evaluation store |
| `results/textsplit_consistency/gene_sets/strict_text_min8_genes.txt` | Eligible-gene allowlist | UTF-8 text with one gene per line, following the split protocol |

The allowlist is an input despite its historical location under `results/`. Its generator is outside this repository; supply the file before using the full-experiment recipes.

## Additional Preprocessing and Variant Inputs

| Path or group | Purpose |
|---|---|
| `data/text_data/ad-alterome-all-data.tsv` | Raw gene-associated evidence for identifier-variant preprocessing |
| `model/text_encoder/S-PubMedBert-MS-MARCO` | Local transformer model directory referenced by `00_prepare_text_stores.sh` |
| `data/gene_id_maps/all_train_eval_genes_EntrezID.csv` | Externally supplied gene-to-EntrezID mapping |
| `data/gene_id_maps/random_gene_alias_seed42.csv` | Random aliases generated by `build_gene_identifier_replacement_tsv.py` |
| `data/noise_text/easy_random_text_train_v2_1000.pubmedbert.npz` | Encoded training noise bank |
| `data/noise_text/easy_random_text_eval_v2_1000.pubmedbert.npz` | Encoded evaluation noise bank |
| `data/benchmarks/v2_textsplit_strict_unmasked_exact/text/*.store` | Unmasked evidence stores |
| `data/benchmarks/v2_textsplit_strict_entrezid_exact/text/*.store` | EntrezID evidence stores |
| `data/benchmarks/v2_textsplit_strict_randomgene_exact/text/*.store` | Random-alias evidence stores |

Noise banks are prepared with `make_synthetic_easy_noise_bank.py` and `encode_easy_noise_bank.py`. Identifier variants are prepared by `00_prepare_text_stores.sh`; unmasked stores use `build_exact_unmasked_textsplit_store.py` with the corresponding unmasked source evidence. These steps require their source inputs and model weights.

## Auxiliary Input Formats

The trainer supports two distinct auxiliary inputs:

| Input | NPZ fields | Trainer option |
|---|---|---|
| Per-instance cell scores | `keys`, `offsets`, `scores` | `--instance-score-npz`, `--eval-instance-score-npz` |
| Gene-level neighbor vectors | `genes`, `vectors`; optional `counts`, `metadata_json` | `--gene-neighbor-prior-npz` |

For per-instance scores, `keys` identify the gene/context distributions, `offsets` delimit their scores in the flat `scores` array, and each score vector must match the corresponding distribution's instance count and order. Use separate score files when training and evaluation stores differ.

The [upstream prior module](stage1_neighbor_prior/README.md) exports gene-level vectors. Per-instance scores require separate preparation. Prior losses and fusion are configured through the alignment trainer's corresponding command-line options.
